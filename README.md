# S6Game

Cocos Creator 3.8.8 竖屏挂机游戏原型，设计画布 887×1774。

当前提供冒险、英雄、背包三个页面；骑士、法师、牧师组成三人小队，每波同时对战三只怪物，清完自动换波。四种怪物使用一张四宫格透明图集，三名英雄各有独立透明图片。

## 本地运行

需要 Windows、Cocos Creator 3.8.8、支持原生 TypeScript 类型剥离的 Node.js（建议22.18及以上），以及安装了 Pillow 的 Python。浏览器构建会将导出的美术转为原尺寸 WebP Q92。

在 Creator 中打开本工程并等待资源导入，然后可以编辑/预览；也可在工程根目录执行：

```powershell
npm test
npm run build
npm run serve
```

默认引擎目录为 `C:\ProgramData\cocos\editors\Creator\3.8.8`。其他安装路径可使用：

```powershell
./scripts/build-web-mobile.ps1 -EditorRoot '你的Creator安装目录'
```

构建后访问 http://127.0.0.1:7456/ 。首次克隆不包含 `build/`，须先构建。Creator CLI成功退出码为36，由构建脚本判断；导出文件校验记录在本地 `logs/`。

## 当前可验证内容

- 三对三行动、前排受击权重、自动/手动技能、护盾、治疗、阵亡跳过。
- 清波后自动刷新；换波间隔冻结技能冷却；失败后短暂整备自动重试。
- 伤害/治疗/护盾飘字及简单位移、缩放演出，不使用Spine或序列帧。
- 前台实际时间收益，与1×/2×战斗倍速分开；金币与各英雄经验在页面同步。
- 挂机每30秒掉落一件真实装备；背包五列竖向滚动、分类、筛选、品质排序及穿戴比较。
- 六槽穿戴/卸下、一键换装与锁定，装备生命/攻击/防御/技能效果实际作用于战斗。
- 批量分解预览与确认，锁定/穿戴装备不可分解；自动保留规则仅处理新掉落，默认关闭。
- 分解获得强化石，装备详情可预览并强化至+10，消耗/规则/强化等级与装备一起保存。

当前收益、升级和战斗数值均为测试配置。已接入英雄独立经验升级，以及带校验和备份的浏览器本地存档；刷新会恢复金币、等级、经验、波次及战斗状态。装备、穿戴归属、锁定和掉落计时也会保留，旧存档自动迁移且不补发历史装备。已支持批量分解、自动保留和强化石强化；离线收益、套装、招募和副本尚未实现。尚未公网部署。

装备数值与每30秒掉落频率为验证配置；等级随最高波次成长，一键换装不抢其他英雄的装备。详情见产品文档第27节。

升级消耗当前等级×40经验，每级提升基础生命、攻击和招牌技能效果的10%，当前上限100级。存档属于当前浏览器与站点地址；切换端口、浏览器或清理站点数据不会保留该地址下的进度。任务完成后本地Git提交，只有明确要求时才推送远程。
