# 第二版界面精校复验

对照入口：[26项精校验收](界面逐项精校验收.html)。切换界面后，可查看参考/修改前/实装三栏，或用透明度滑块核对位置。修改后图片为430×764视口、2倍像素比的原尺寸无损WebP。原始效果图仍在[效果图合集](第二版界面效果图合集.html)中。

本次对照覆盖26项参考界面，另验证3种副本结算。已通过118项模型检查、29界面交互、5种手机尺寸共145组几何检查、28组主页面适配、英雄页4种尺寸及47px模拟安全区。检查范围包括弹窗和按钮内容边界、五列方格、两行半/三行半视口、技能卡、英雄立绘和图片加载；额外检查招募结果两按钮中心没有九切片透明缝。

实装保持四名英雄和真实装备、奖励、概率、保底、技能、消耗。参考图中的示例数据和额外角色未作为玩法实现。独立生成的插画与原图仍有构图和笔触差异，自动检查不代表逐像素一致。

## 第二轮精修（2026-11-21）

本轮再次逐张对照全部26项，修改前截图来自上一轮提交版本。冒险页提高了底部英雄信息与技能区域的占比，重绘低地平线森林，角色按实际操作栏和草地地平线布置；脚底阴影跟随角色移动，阵亡后隐藏。模拟安全区改变时，在视口高度不变的情况下也重新计算站位。

体力消耗、当前体力、扫荡按钮统一使用资源栏图标及颜色。金币、经验、强化石和招募券复用各自资源；无尽与每日奖励图标不再被通用行样式缩小。补齐招募标题月桂/丝带、UP角色名牌、常驻券、UP券、保底皇冠、详情/记录小图标、带叶标题牌及结果页金色星芒装饰。人物与文字保留真实交互，不烘焙进背景。

继续校准短屏英雄区、品质格高光、弹窗标题牌高宽、内容留白、属性行、按钮、卡池规则、编队/结果卡全身立绘与职业角标。每个界面的具体修改写在对照页对应条目中。分解选中状态复查发现Cocos构建将Set展开编译为数组拼接，导致材料预览为0且分解失败；改用`Array.from`，以真实选中8件、材料入账及刷新恢复验证修复。

新增几何检查：后排脚底在地平线下方、最低血量文字不压住操作栏、森林底部衔接信息区、底部信息和导航占屏至少30%、同种资源图片与色彩一致、奖励图标占格比例。所有浏览器验收使用独立测试存档。

另通过实际Cocos战斗节点检查五次换波、四种怪物贴图、位移/缩放/旋转后的脚底阴影和阵亡/重置状态；四种屏幕下按贴图透明边界验证脚底落地，避免只检查布局计算值。

## 重新生成并验证

在项目根目录执行。需要Cocos Creator 3.8.8、已安装的Node依赖、Chrome、Python及Pillow。浏览器验证使用独立会话，不读取或覆盖玩家浏览器的存档。

```powershell
python scripts/prepare-fidelity-art.py
npm run build
npm run serve
```

服务器运行后，在另一个终端执行：

```powershell
npx tsc --noEmit
npm test
npm run test:main-layout
node scripts/verify-hero-layout.mjs
node scripts/verify-battle-art.mjs
npm run test:ui

$env:S6_WIDTH = '430'
$env:S6_HEIGHT = '764'
$env:S6_SCREENSHOTS = 'temp/ui-audit-round2/after'
$env:S6_AUDIT = '1'
npm run test:ui
python scripts/generate-fidelity-review.py --captures temp/ui-audit-round2/after
Remove-Item Env:S6_WIDTH, Env:S6_HEIGHT, Env:S6_SCREENSHOTS, Env:S6_AUDIT
```

最后一步保留已提交的修改前预览，不会把新截图冒充旧截图；首次另存旧版本时可以用`--before <旧截图目录>`明确指定。模型随机招募与时间数值可能不同，版式及图片尺寸检查保持一致。默认`test:ui`更新390×844的实装验收；指定截图目录时不会覆盖该验收页。
