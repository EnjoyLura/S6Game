Use case: ui-mockup / production game UI asset atlas.
为竖屏明亮 Q 版奇幻游戏《挂机传说：无尽征途》重新生成并整理“装备详情弹窗”的可裁切美术资源。只输出一张高清正方形 PNG 图集，推荐 2048×2048，真正透明背景，保留 alpha；所有部件正视、无透视、清晰干净、独立完整、互不接触。不是手机截图，不是设计说明海报。

参考图 Image 1（弹窗-装备详情-v1.png）是唯一造型与风格依据。严格匹配图中中央弹窗：圆润蜂蜜金色外框、浅奶油纸面、薄暖棕轮廓、金橘色下缘厚度、少量青黄绿色叶片、小型六角切角标题牌、橙色圆形白叉关闭按钮、杏桃次按钮、亮金黄主按钮、紫色装备品质格、银白长剑与金色护手和紫宝石。保留轻柔手绘卡通体积、柔和高光和紧贴部件的阴影，手机尺寸依旧轮廓清楚。不能改成写实金属、暗黑、蓝色、冰雪或复杂巴洛克雕花。特别注意：去掉按钮内部白色细边和白色内环，允许自然的面状柔和高光。

排版是一个资源大图中的三块清晰独立区域，没有可见分区框、网格线、文字标题或编号。四周留约 4% 的透明安全边距，各资源间有足够透明间距。大资源以单图呈现，中等资源用 2×2 四宫格，小资源用 4×4 十六宫格；不要把大面板缩成小图标。

左侧约 46% 画布：一个单独完整的大弹窗空白底板，纵向圆角矩形，宽高比例接近参考中央弹窗约 0.78。顶部正中连接一个紧凑横向切角奶油金标题牌，牌内留白；标题两侧各少量绿叶，左右下角各一个参考同款绿叶角饰。连续圆润金色框包围平整浅奶油内纸面，层次和边框粗细严格接近参考。内部完全空白，无图标、分割线、按钮、装备、文字、数值；不把右上关闭按钮烘焙进底板。标题牌、内纸面和叶饰作为这个大底板的一部分连贯完整。底板无遮挡，不裁断任何角或叶片。内纸面必须是实心奶油色，不透明洞；底板外是透明区域。

右侧约 46% 画布的上半区：规整 2×2 四宫格，每格一个中等尺寸资源，居中，透明留白，顺序从左到右从上到下：
1. 紫色史诗品质方形装备图标卡，圆润紫色边框和浅紫内缘、紫色渐变底，小型四角星闪光；内部完整银白长剑，剑尖朝右上、金色护手和圆形剑柄尾端朝左下，护手中央紫色菱形宝石。严格参考原图的剑，不加等级和文字。
2. 杏桃色圆角胶囊次按钮空白底，与参考“强化”按钮一致，暖橙外缘、轻微下侧厚度和轻柔面光，没有白色内描边，没有字或符号。
3. 亮金黄色圆角胶囊主按钮空白底，与参考“穿戴”按钮一致，金橙外缘和轻微下侧厚度，没有白色内描边，没有字或符号。与次按钮同尺寸同弧度。
4. 一条横向浅杏桃圆角属性行空白底，扁而长、柔和均匀，参考攻击/生命/暴击率属性行，不带图标、字、数值、描边或装饰。

右侧下半区：严格 4×4 等大透明单元格，16 个独立小资源，按行排序；小图标统一视觉尺度，横向胶囊在其单元格中保持横向，完整留白，不伸入相邻单元格。以下每格仅一个部件：
第一行：橙金圆形关闭按钮配粗白色叉号、金棕色闭合挂锁、同款打开的挂锁、深暖棕色攻击短剑实心符号。
第二行：深暖棕色生命爱心实心符号、深暖棕色暴击多角星芒实心符号、深暖棕色技能伤害火焰实心符号、参考图的绿色爱心加两支循环箭头的恢复效果图标。
第三行：参考分区标题前的暖棕色双叶小枝、紫色四角菱形星芒、金色小菱形点缀、金色三瓣叶形分隔装饰。
第四行：独立空白紫色品质圆角胶囊标签底、独立空白浅杏色等级圆角胶囊标签底、独立空白淡金黄色分区圆角胶囊标签底、独立空白紫色方形装备品质框（内紫色底，无剑，无星光）。
