# 冒险页最小战斗原型

## 范围

本轮实现 Cocos Creator 3.8.8 真正运行的 2D 场景，设计尺寸 887×1774；一个骑士对一只史莱姆。不是完整三人 RPG，也不是将效果图作为整张界面运行。

- 森林背景、独立角色精灵、呼吸/前顶/回位/受击变色/伤害飘字。
- 双方交替行动、生命条与具体生命数字、胜利/失败、重新挑战。
- 一个守护技能：自动或手动排队，在骑士行动时替代普攻。
- 1×/2×、暂停/继续、输出统计。
- 五个导航入口已排布；英雄、招募、背包、副本与阵型仅提示尚未纳入样例，不提供对应系统。

## 临时测试规则

数值集中在 `assets/scripts/BattleModel.ts`，不是正式平衡方案：骑士生命1980、攻击128；史莱姆生命940、攻击105；每1.25个模拟秒行动一次，骑士先行动。守护产生220护盾、冷却8个模拟秒。倍速同时推进战斗与冷却；暂停、页面进入后台、结束后不推进。手动技能不额外插入行动。重试恢复双方生命、护盾、冷却和统计；保留自动技能偏好。

本次没有挂机收益、存档、装备、经验、天赋、招募或多波成长。不能用本样例验证这些系统。

## 初始化、构建与预览

安装版 Creator 3.8.8 的 CLI 提供 `--project` / `--build`，未提供独立 create 子命令。初始化脚本通过命令行复制安装包自带 `empty-2d` 模板，只补齐不存在的模板文件；Creator CLI 随后导入资源并构建。

在项目根目录运行：

```powershell
./scripts/init-cocos.ps1
./scripts/build-web-mobile.ps1
node scripts/serve.cjs
```

预览地址：<http://127.0.0.1:7456/>。默认仅本机可访问。不要直接双击导出的 index.html；Cocos 资源加载需要 HTTP 服务。

引擎：`C:\ProgramData\cocos\editors\Creator\3.8.8\CocosCreator.exe`。
导出目录：`build/web-mobile`。配置：`build-web-mobile.json`。
实际调用：`CocosCreator.exe --project "D:\AI\S6Game" --build "configPath=D:\AI\S6Game\build-web-mobile.json"`。
脚本校验 Cocos 成功退出码36及导出入口；日志在 `logs/build-stdout.log`、`logs/build-stderr.log`。
